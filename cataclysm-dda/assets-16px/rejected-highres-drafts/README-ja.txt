CDDA Original 16px アセット

対象は Cataclysm: Dark Days Ahead 0.I-1 (Ito-1)、固定コミット
7b2efa5cea38e4d4d97dd0e63b28b9148623da59。

このフォルダは本体のリンク・既存タイルセットから独立しています。
sprites/ の各PNGは実寸16×16、RGBA、共通32色パレット、アルファ0/255です。
raw/ に生成時の大きな原本、prompts.json に実際の生成プロンプトを保存します。
prepare.py はnearest-neighborで16×16に出力し、パレットとアルファを揃えます。
previews/ は16倍表示、contact-sheet.png は10倍と原寸を並べた確認画像、
contact-sheet-native.png は原寸一覧です。index.html は画像表示用です。
拡大画像とアトラスは16×16より大きくなりますが、個別ゲーム画像は16×16です。

範囲と進捗
status.json に対象数、作成数、専用対応、共用対応、未対応を記録します。
id-manifest.csv に全ID候補を収録し、manifest.json に出典と画像の対応を残します。
専用は各画像の先頭の指定ID、共用は人物の性別/NPC・水の内容物などの明示指定、
または上流で明示された looks_like の最大10段の対応です。名前の類似で推測しません。
同じ画像を使う場合も「共用」であり、個別の絵を作成済みとは数えません。
unknown の ? 記号は未対応用のコード作成ユーティリティです。
未対応が ? で表示できても、そのIDのアート作成完了とは数えません。

一覧の母数は data/json の8種類の描画カテゴリに属する明示ID候補と
上流 CPP_IDS などの固定実行時IDです。抽象継承元は除きますが、古い移行用定義や
PSEUDO項目を含む場合があり、現在の実行時に読み込まれる全表示物の数ではありません。
Mod、車両のvariant、フィールドの強度、広域マップの回転や接続形状、死体、
装備・変異の重ね描き、季節差分などの動的派生IDはこの母数に含めません。
それらを含めた完全なCDDA用タイルセットは未完成です。

導入用データ
tileset/CDDA16_Original/ にCDDA標準形式の tileset.txt、tile_config.json、
tiles.png を用意します。tile_info の width と height は16、pixelscale は1、
iso はfalseです。PNGは各セル16×16のアトラスにパックしています。
原本・既存表示・セーブ・ゲーム処理・日本語データを上書きしていません。
ゲームでこのタイルセットを選択する設定は変更していません。

本体担当が導入する場合
1. 本体の最終リンクと現在の検証を終えてから、現在の配布パッケージを複製します。
2. 複製したパッケージの gfx/ に CDDA16_Original フォルダを新規追加します。
   pristine upstream/gfx や既存タイルセットには書き込まないでください。
3. native版では「設定 > グラフィック > タイルセット」で
   CDDA Original 16px (partial artwork) を選びます。
   TILES がタイルセット選択、USE_TILES が描画切替の上流設定名です。
4. Emscripten版の配布はパッケージのgfxファイルを事前ロードする方式です。
   単にHTMLの隣へPNGを置いても自動認識しません。配布元の新規gfxを入力とする
   本体担当の再パッケージ処理か、対応する仮想FSへの登録が必要です。
   このアセットタスクでは再リンク・再ビルド・仮想FS変更を行いません。
5. 複製版で屋内/屋外、人物/モンスター、アイテム、炎・罠、表示倍率、
   ロード/セーブ、未対応の表示を実機確認します。

未対応IDが多いため、本体の標準タイルセットとしての採用はまだ検証対象です。
既存タイルセットの読み込み設定へマッピングだけ混ぜると画像インデックスが
違うため誤表示になります。タイル寸法の異なる既存アトラスとも混ぜないでください。

出典と制作
ゲームID・対応形式の確認: 固定版の data/json、doc/TILESET.md、
src/cata_tiles.cpp、src/sdltiles.cpp、tools/json_tools/generate_overlay_ids.py。
画像: この依頼のために built-in image_gen で新規生成。
既存CDDAタイル画像・他作品の画像を複写、縮小、転用していません。
ユーティリティの ? と透明空白のみ新規にコードで作成しています。
ゲーム本体の配布条件は本体のNOTICE・ライセンスを引き続き保持してください。

継続作業
24種の最初の範囲が揃っても全ゲーム用アートが完成したとは扱いません。
未対応はid-manifest.csvのstatus=unsupportedで抽出できます。
次の優先範囲はゾンビ兵士・特殊ゾンビ、閉鎖/破損窓、階段・水域、
収納・キッチン、武器・食料・薬、車両のドア/シート/フレームなどです。
