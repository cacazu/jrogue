```sh
node tools/serve-integration.mjs
```

Open **http://127.0.0.1:3000/**. The dependency-free server binds only to loopback; Ctrl+C stops it. Use the same browser origin and port to retain local IndexedDB saves. See [the local controls guide](LOCAL-CONTROLS.md) for controls, native save-and-quit and the storage contract.
