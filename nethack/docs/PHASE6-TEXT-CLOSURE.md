# Source text closure beyond prepared direct calls

This checkpoint targets the preserved official C game with Rust presentation,
commands and platform adapters. All artifacts here are source proposals. They do
not establish Japanese runtime coverage or an active callback count, and they do
not change the frozen phase3 catalog, upstream source, generated engine work,
game rules, save data or RNG. Delivery remains local HTML plus Node/browser
verification; external publication is outside the current scope.

The pinned official source is NetHack 5.0.0, commit
`16ff59115315917b93185d026aeefea06db9b0f4`. The original source and its notices
remain available. New phase6 resource work imports no Japanese fork paths.

## Direct C call denominator

The core inventory has 6,175 literal call sites and 5,984 unique source message
IDs. Phase4 source preparation covers 5,000 IDs. The separate diagnostic
preparation covers 559 `impossible` IDs. The remaining 425 IDs cover 432 lexical
sites: panic 173, configuration errors 162, live logs 92, dump output 3,

translations in category C, leaving 423 newly queued remaining IDs.

`locales/phase6/static-batches.json` partitions the 423 new IDs into three
141-ID queues and the 559 diagnostic IDs into four queues. Their original
typed unions, `%c` byte contracts, numeric widths, string precisions,
preprocessor uncertainty and error channels remain explicit. A translated
error may not suppress its callback, change recovery, or create a callback in
an inactive native branch.

The 997 paired author rows and 3,196 prepared-primary author rows have passed
source/schema verification. These 4,193 reviewed proposals include explicit
public-producer dependencies and opaque whole-buffer envelopes. They are not
4,193 proven complete Japanese runtime messages.

Use `verify-resource-audit.py --input <resource-batch.json>` for those

its established direct-call schema. These validators prove source provenance
and contracts; they do not prove Japanese semantics, producer lifetime,

## Knowledge, syntax and persistent data

Rumor player IDs use the public wording namespace `nethack.resource.rumor`.
They contain no truth/false bucket. Offline provenance records the source
file, but player events may only describe the original selected visible
rumor. Original random selection happens once.

Hallucination labels preserve the original `bogusmon` gender/personal-name
code and its source-selected display result. C strips that prefix before
display; templates do not print it. Deity labels similarly preserve the
original goddess code while `align_gname` strips the leading underscore.
Neither descriptor permits inspection of a real hidden monster, gender or
unselected deity.

English encyclopedia lookup keys, Lua monster/object IDs, map fragments,
portal identities, option aliases and command tokens remain original native
input values. Their separately selected display descriptions may be
localized. User names, typed input and file paths require the actual source
consumer's literal-data contract; their spelling is not evidence of a
source-owned translation.

Predefined engravings and names remain original native data for gameplay,
save/load and degradation. Localizing an intact, source-proven displayed
field must not alter `Elbereth`, parser keys or damaged text. Untracked
custom/degraded text retains literal fallback. No completed-English matching
can recover an origin or hidden identity.

## Source-specific permissions blockers

`resource-rights-audit.json` preserves the exact original notice lines and
source hashes. Each encyclopedia body records its original lookup keys,
complete multiline attribution and exact source span. The 387 attributed
entries do not have supplied excerpt-specific translation permissions. The
128 entries with `[]` or missing citations remain authorship reviews; absence
of attribution is not an established license or a visibility exemption.

Each of the 561 tribute units records its exact source book/Death quote
title, passage directive, page/comment evidence and source span. The wrapper
credits Robert Patrick Rankin and the tribute identifies Terry Pratchett;
the NGPL redistribution wrapper is retained. It does not provide an
excerpt-specific permission to translate an entire proprietary book passage.
No complete Japanese book excerpt has been authored. Original English assets
and attributions remain intact while those rights are unresolved.

This blocks 1,076 encyclopedia/tribute units from the ordinary authoring
queues pending individual permissions, established original authorship, or
an explicitly approved facts-only replacement. The resource producer gap
must remain visible while unaffected original game text is completed.
