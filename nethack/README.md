# NetHack 5.0.0 ローカルWeb

公式 **NetHack 5.0.0** の全ゲーム処理を C のまま維持し、表示・入力・アプリケーション境界・環境依存部分を Rust とブラウザーアダプターに分離するプロジェクトです。旧 JNetHack のフォークとは別の公式ソースを使用しています。ほかのゲームは変更しません。

現在の依頼範囲は **ローカル HTML と Node／ブラウザーテスト** です。この配布で使用するランタイムは、完全な公式 C エンジンと不変カタログを統合し、実ブラウザー検証を通過した Phase6 です。`build/phase6/web/` の検証済みファイルを、対応ソースの検査後に `web/` へ反映します。日本語 UI が既定で、未対応の本文は元の英語を表示します。新しい外部 Site 公開や既存 Site の公開範囲変更は依頼範囲に含みません。全文日本語化は未完了です。

## ローカルで開く

Node が利用できる環境で、この `nethack` フォルダーから実行します。

```sh
node tools/serve-integration.mjs
```

ブラウザーで **http://127.0.0.1:3000/** を開きます。追加パッケージは不要で、サーバーはローカル端末のループバックアドレスだけに待ち受けます。終了は Ctrl+C です。HTML・JavaScript・JSON・WASM を HTTP 経由で読み込むため、このサーバーを使用してください。セーブはブラウザーのオリジン単位で保存されるので、同じアドレスとポートを使います。

操作・保存の説明は [ローカル操作ガイド](docs/LOCAL-CONTROLS.md)、実測結果と制限は [現在の状態](docs/STATUS.md)、残りの検証は [日本語統合の実行計画](docs/PHASE3-EXECUTION-PLAN.md) を参照してください。

2026-10-02 の Phase6 は公式 C／Lua 177 単位の完全ビルド、Rust 67 テスト、整形検査、strict offline Clippy と WASM 用静的ライブラリーのビルドに成功しました。再生成した `nhdat` は、元のターゲット WASM リーダーによる 4,859 検査をすべて通過しています。対象は五つの原版リーダー関数で、百科事典リーダーの実行や全リソースの利用を検証したものではありません。

このランタイムで使用する Rust は `tools/semantic-text/phase6-immutable-catalog/rust-copy/`、エンジン記録は `build/phase6/engine-manifest.json` です。ルートの `rust/` と `build/engine-manifest.json` は以前の Phase3 の記録として保持します。ルートの既定 Cargo 手順だけで現在のランタイムを再生成できるという意味ではありません。対応ソースでは選択した Rust とビルド元の対応を明示します。

選択したカタログは英語 9,618 件、日本語 5,687 件です。r4 では構文 17 件、実コンパイル済み境界 32 件、通常 Chrome 18 件、詳細なネイティブ Chrome 14 件がすべて成功しました。後三つの合計は 64 件で、構文検査や Rust テストとは別の件数です。過去三回のブラウザーテスト条件の不一致は証拠を保持したうえで修正し、同じエンジンのファイルを再検証しました。

この文書は実測済みランタイムの対応ソースに含める記録です。[Phase6 の検証記録](build/phase6/verification.json) は選択したソースと実行結果を結び付けます。アーカイブの実展開、ソースだけの準備再実行、対象フォルダーへの反映、Node でのローカル配布ファイル取得の結果は、ソースアーカイブとは別に配布する `build/local-delivery/phase6/` と `build/local-phase6-promotion.json` の最終レポートで確認します。ここには未実測の監査成功やバイト一致の完全リビルドを記載しません。

Phase3 の 49 Rust／95 境界・ブラウザー検査と、後続の失敗証拠は履歴として保存しています。13 職業、PC／モバイル入力、保存と新規モジュールでの再開、スコア保持、描画時の状態・乱数不変性は代表的な実行検証です。900 の動的生成箇所、クエスト、アクセシビリティ修飾、リソース文章の接続、死亡・bones と全キャンペーン、実機 iOS／Safari には未検証部分があります。証拠と制限は [現在の状況](docs/STATUS.md) に記録しています。

意味 ID は元の生成箇所から発行し、表示済み英語の逆引きでは生成しません。英語の元処理によるフィルター・履歴・音声処理を維持し、公開済みの引数を固定して Rust に渡します。描画・再描画・言語変更でターンや乱数を進めません。未知の ID や未対応の名前構成は元の英語に戻します。
