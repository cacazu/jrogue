# First read-only state witness implementation

This is an authored, **unintegrated and unexecuted partial witness**. All new code is confined to [experiments/state-probe](../experiments/state-probe). No original source, overlay, source generator, runtime, save behavior or existing probe was changed. The parent owns compilation, integration and execution. This document implements the first useful slice of [the coverage audit](STATE-PROBE-COVERAGE.md) and [the design](../localization/STATE-PROBE-DESIGN.md); it certifies no full-world rendering purity or save equivalence.

The code captures original MT continuation state, native run/control scalars, the retained command byte, automatic movement continuation and ordered targeting state. A separate codec captures the actual browser IO FIFO and deferred key jobs. It always reports `Complete=False`. Lua, world/entity/scheduler/UID graphs, suspended stack locals and other platform state remain explicit missing sections.

## The queue is a platform boundary

DRL does not contain a native queue of `TCommand` records. Native command dispatch is immediate. In [game.mjs](../port/web/game.mjs), `createEventQueue` owns ordered `{bytes, receipt}` packets plus `lastEnqueuedReceipt`, `consumedReceipt`, `consumedPacketCount` and nullable `textReceipt`. The last field gates polling/pending after kind-10 text delivery until presentation acknowledgment; it is included explicitly. `createKeyPressQueue` separately owns ordered deferred jobs, their original event DTO, token, tap/release/acknowledgment state, stage/receipt and global token/presentation counters.

The browser owner snippets copy those arrays synchronously without polling or pumping, then pass their direct fields to the authored codec. All 128 bytes of each already-defined input packet are retained in FIFO order; this is a wire packet, not arbitrary Pascal record memory. Event fields are encoded in stable code-unit key order, with typed values; accessors, symbols, unsupported/nested values, unsafe integers and invalid Unicode fail with an exact error path. Strings are size-checked before UTF-8 allocation. No locale, string replacement, getter, clock, dispatch, RNG or renderer is called.

[core-host.mjs](../port/web/core-host.mjs), 126–127, consumes this FIFO through `pollEvent`/`eventPending`. [vbrowserio.pas](../core-overlay/fpcvalkyrie/src/vbrowserio.pas), 94–120, updates driver modifiers/mouse/buttons while polling. [TDRLIO.CommandEventPending](../native/drl/src/drlio.pas), 1137–1155, can discard events and invoke `OnEvent`; [TIO.ClearEventBuffer](../native/fpcvalkyrie/src/vio.pas), 275–279, consumes events and updates pad state. None of these methods is used for capture.

Held keyboard/mouse/pointer state, Rust normalizer state, IME composition, driver key/pad/modifier state and modal layers are not yet captured. Input/deferred-key state is also distinct from gameplay state: native-frame acknowledgment can deliberately release a deferred key. A pure draw replay that neither acknowledges a new native frame nor queues input should preserve this slice. Do not hide acknowledgment changes by omitting the queue.

## Canonical bytes and failure contract

The 16-byte header is `DRSP`, U16 schema `1`, U16 encoding `1`, U32 section-family flags, a zero `Complete` byte and three zero reserved bytes. Flags identify requested/implemented families, not proof of complete gameplay: bits 0–2 are native RNG/command/run families, bit 3 is platform input.

Each record is U16 ASCII tag length, exact stable English tag bytes, U8 kind, U32 payload byte length, then payload. Integer widths are explicit and little-endian. Kinds are U8/U16/U32/U64/I32/Boolean/original string bytes/byte array/U32 array, numbered 1–9. Arrays carry U32 element count. Booleans are 0 or 1. Negative I32 values use explicit two's-complement arithmetic. Original `RawByteString` values are preserved byte-for-byte; browser entry UTF-8 configuration establishes the browser string boundary, while native code-page equivalence still requires its declared build context.

The writer touches only its newly owned bounded buffer and metadata. It calls no save writer, stream serializer, gameplay getter, hook, statistic update, clock or RNG method. No object/record padding, process address, locale formatting or hash computation enters the core witness. Output is a detached copy. Hash it outside the original core after capture.

An invalid budget, non-frozen request, absent core/RNG, invalid MT index, distinct Lua RNG, malformed/oversized path/target ring, unsupported queued value or overflow fails. Reported failures contain **zero bytes** and an English semantic error ID plus path; tests must reject failed results before equality/hashing. The native coordinator converts ordinary allocation/other exceptions to failed results. Direct writer/JS allocation failures or runtime traps can still throw: integration must invalidate the previous capture first and reject any thrown/absent result, never reuse old bytes. Unsupported world/Lua/general-platform sections instead have explicit `.covered=False` and `.reason` records, and the header/result always retain `Complete=False`. No complete-state comparison may accept this prototype.

## Concrete integration design

1. Check the hashes and unique declaration anchors in [integration-plan.json](../experiments/state-probe/integration-plan.json). Add the independent writer to the reviewed build source. Introduce nonvirtual owner methods and interface free functions under `DRL_STATE_PROBE`, add the writer to those interface `uses` clauses under the same define, and include each owner implementation immediately before its unit's final `end.`. Apply this through parent-owned generated/overlay copies; retain pristine/native selections unchanged.
2. Integrate in dependency order: writer; RNG, target-list and path owners; being and multimove owners; player owner; run/global owners; coordinator. These seams perform direct owner reads and do not change constructors, command execution, serialization, RNG sampling or rules. Keep compiler-used-source records and exact codec/ledger/build hashes.
3. Keep the current DRLP fast diagnostic intact. A separate authored export should capture `CaptureNativeControl` once into an immutable bounded buffer while the browser is verifiably suspended; subsequent length/chunk reads copy that buffer and never revisit game objects. Pass identities from the frozen build/ledger, rather than an arbitrary browser string. The prototype coordinator is not yet called or exported by any runtime.
4. Apply the owner-local platform snippets and capture native plus FIFO/deferred-key sections in the same synchronous suspended turn, with no `await` between them. A browser `paused` flag proves JSPI suspension only; it does not close action/modal/`TDRL.Run` stack-local coverage. Add a stronger safe-point classification before claiming continuation equivalence.
5. Select buffer/node/entry limits from measured baseline states. The authored 4,096-node/entry bounds and 256 KiB platform default are review proposals; exceeding a bound rejects a witness, never silently shortens it. The maximum writer allocation is 16 MiB. Record compiler/browser results separately when the parent performs them.

There is no integrated patch, generated-tree regeneration, compiler invocation, browser invocation, Cargo invocation, Git write or runtime fixture result from this delegated task.

## Fixture sources and acceptance still required

The standalone writer fixture checks literal header and little-endian bytes, signed-minimum encoding, detached output ownership, repeated finalization, writes after sealing and overflow. The original-RNG fixture checks every seeded MT word with a wide-arithmetic source oracle, exact index/count framing, repeated paused captures, unchanged future output against a fresh original `TRNG` over 1,300 draws spanning two twists, state-change detection after a draw and empty failed output. It uses actual original RNG methods only to arrange/check the fixture outside capture; it never uses native serialization.

The five authored Node fixtures check source-array/byte preservation, immutable detached output, off-head packet mutations and FIFO order, receipt/deferred-key changes, explicit frozen/size/type/version/Unicode failures, and accessor rejection without invoking a getter. Their source is ready for parent review; no passing count is claimed.

Before closing this slice, the parent must compile the owner seams and run these fixtures against exact recorded source. Add original movement/target fixtures that change direction/count, remaining tail coordinate/order, current target and entry links; require the corresponding witness to change, then capture twice without further mutations. Test path cycles/target broken links and every budget failure. Capture real paused original states twice; verify capture itself leaves native RNG, control fields, IO FIFO and Lua stack unchanged. Use source-derived traces to verify queued commands continue identically after capture.

Before full-state purity or save claims, implement/disposition the missing native entity/map/scheduler/UID state, Lua alias/cycle/metatable/function/upvalue graph, general pathfinding and liveness graph, IO/held/IME/normalizer/visual state, and suspended continuations. Classify timing fields by their actual readers: stored frame/pad times can affect subsequent input, so they are retained rather than assumed harmless. Original Save & Quit's expected statistics/time changes must remain separate from diagnostic capture. This milestone is actionable source code and integration design, not a complete game-state certificate.
