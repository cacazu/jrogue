The concise spell Info column now has a source-owned EffectDescription projection. The original get_spell_info traversal, dice_roll calls, SET_VALUE/CLEAR_VALUE history, duplicate test and every formatting call remain byte-identical after removing AB_EFFECT annotations. Native spell rows still use help[30]. Browser rows publish the captured graph as row.<sidx>.info only at the original worked-spell gate; all other states clear that field.

web-spell-preview.c owns one latest snapshot until the immediately following row consumes it. It copies integer facts and reviewed lexical IDs from winning native branches. It never reads a completed preview buffer or repeats effect_info, dice, damage or knowledge calculations. Canonical effect indices select immutable list-effects.h info-field bindings and are kept out of emitted JSON. A missing, malformed or over-capacity capture is explicit unsupported data; no English-output lookup occurs.

The shared EffectDescription formatter reproduces the original ASCII N-1 clipping at the outer native Info capacity and selected special[40] suffix. Japanese reflows the same selected facts. Preview grammar intentionally retains the native one-die dN form, suppressed nonpositive base, BALL zero-radius `rad 2` separator quirk, SPHERE zero-radius `, rad 2`, and SHORT_BEAM's already computed clamp. It does not replace those rules with the separate full-description grammar. A truly empty preview uses the existing reviewed angband.effect_info.grammar.empty leaf.

The source inventory and bilingual schema live under migration/spell-preview-data. producer-snapshots.json pins three original player-spell functions and two existing adapter functions; Node checks independently compare the native player-spell functions with the pinned official Angband 4.2.6 source, validate catalog fields/placeholders and test full-width dice and clipping examples. This is a source-only integration; the parent still owns the required native/Rust/WASM compile and real-browser worked/unworked spell-row acceptance gate.
