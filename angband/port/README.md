# Angband 4.2.6 日本語 Web 移植

原作 Angband の C エンジンとゲームデータを保ち、Rust の入力・アプリケーション・表示・保存処理を接続したローカル HTML 版です。日本語を既定にしています。日本語化と表示コードの分離は段階的に進めており、完全移植とは表示していません。

公式版は `4.2.6`、固定コミットは `f3082213b73f3e463e3d0d60bff4b00462beae6e` です。未変更の原作は隣の `../upstream/angband-4.2.6/`、改変版はこの `port/` に分けています。出典、アーカイブのハッシュ、ライセンスは [PROVENANCE.md](docs/PROVENANCE.md) を参照してください。

```powershell
$env:ANGBAND_BUILD_JOBS = '1'
node tools/build.mjs
node web/server.mjs
```

ブラウザーで `http://127.0.0.1:4173/web/` を開きます。Node、Rust の `wasm32-unknown-emscripten` ターゲット、設定済み Emscripten SDK を使用します。SDK の既定位置は `C:\Users\kit\emsdk`、変更は `ANGBAND_SDK` 環境変数です。取得した configure/install は実行しません。

成果物は HTML、WASM、元データ、英語・日本語 JSON、ライセンス、対応する `source.zip` です。今回の WEB 公開の範囲は Node によるローカル起動と実ブラウザー検証です。外部への公開は行っていません。[verification.json](verification.json) は直近に受け入れられた成果物の記録です。追加した表示・保存、通常プレイでの死亡、原作の知覚とアニメーションの代表的経路を、同じ最終エンジンで確認しています。配布物全体の受け入れは、この記録とビルド・パッケージの manifest で確認してください。過去の受け入れ結果を現在のソースや別のバイナリーへ流用しません。

メッセージの再表示・検索、第二キャラクター画面の装備／耐性／能力維持表、Enter とコンテキストメニュー、見る・対象選択の文章、時系列のゲーム履歴、知識画面の状態と集計、キャラクターの日本語テキスト出力、宝箱の罠メッセージは、原作の生成箇所から意味 ID と型付きの値へ接続しています。現在の接続と未検証の分岐は [COVERAGE-AUDIT.md](docs/COVERAGE-AUDIT.md) と [migration/coverage-audit.json](migration/coverage-audit.json) を参照してください。ソースの接続や辞書の登録件数は、全ゲームの翻訳率や全分岐の実行証明ではありません。

Rust が原作で選ばれた事実と文章の引数を受け取り、日本語を表示します。原作の ASCII 端末には英語が残り、日本語の意味表示は別の領域で折り返します。プレイヤー名、ユーザーのメモ、編集した伝記、銘、外部の名前は翻訳しません。元の文章から意味 ID を推測する置換は行いません。

保存形式 v3 は初期状態と所有する入力履歴から元のプロセスを再構築します。対応する入力待ちでは、選択画面の途中、表示キャッシュ、入力下書き、全 38 RNG ワードを含む再開を照合します。中断した C スタックを保存する方式ではありません。エンジンやデータが異なる保存は黙って読み替えず、明示的に拒否します。旧形式と原作保存の観測用サイドカーは個別の検証結果を参照してください。

[移植契約](docs/MIGRATION.md) に四層の対応と残作業を記載しています。原作のゲームルールを簡略化した別ゲームではありません。ブラウザーの再描画・言語・フォント・表示領域の変更はコピーした事実を使います。原作の幻覚・知覚・色アニメーションが行う共有 RNG の呼び出しとゲーム処理の順序は変更しません。通常の長期キャンペーン、闘技場、任意の音声・画像タイル・副端末・ゲームパッドには、未対応または未検証の範囲が残っています。

タイル・音声・ゲーム専用フォントは Web 版に配布せず、文字表示とシステムフォントを使います。原作の著作権表示を保ち、GPL v2 の選択肢に従って改変版と対応ソースを配布します。依存コードの通知も `licenses/` に含めています。

次の受け入れと未対応範囲は [NEXT-MILESTONE.md](migration/NEXT-MILESTONE.md) に記載しています。完全移植、完全な翻訳、通常プレイでの全階層クリアは未達です。
