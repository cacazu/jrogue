## Explicit sources and body identity

The accepted historical road profile used native gameflow `tome-native.mjs` / `tome-native.wasm` from `physical-input-compat-game-flow-build`. These two exact artifacts are selected; original archives/assets/savefiles, object files, target directories and unrelated games are excluded. The unchanged physical Rust WASM, retained C/Lua WASM and semantic Rust WASM are referenced from guarded phase6 dist paths, without copying a second base checkpoint. This profile uses the default 24,826-ID localization catalog; it does not silently swap phase6's independent 24,846-ID merged semantic experiment.

`derive_gameflow.py` is a pure text/data transcription of the exact current server's HTML, browser script, pointer-host, owner and physical54-label derivations. It reads raw UTF-8 bytes to retain input CRLF and uses reviewed single-occurrence source anchors. It never imports original game scripts or invokes callbacks/simulation/RNG. Freeze compares every recorded served artifact SHA/byte count against its candidate body or selected/shared source. Routes absent from the historical served-artifact record remain newly frozen candidates, not retrospectively verified routes.

The original profile overwrites `/textbox/native-textbox-fixture.lua` with `native-core-work/textbox-web/native-textbox-fixture-trace.lua`; the portable config preserves that final override. Native canvas/textbox/pointer/UTF8 Lua sources are transitive dependencies of gameflow, not separately enabled untested profiles. `pending-profiles.json` records future textbox and full-frame paths/unknowns explicitly.

The portable factory invokes the guarded shared original-range adapter with explicit phase7 native root, phase7 VFS manifest, default bootstrap/retained/localization/review roots and phase6 retained/semantic binaries. It adds only the selected exact body routes. VFS rebasing changes physical/original/staged locators, preserving virtual names, pack mount order and legacy metadata. Pristine upstream archive references remain read-only; no assets are copied. Recorded old VFS `bytes` fields are not promoted to current file identity; the source index measures actual selected bytes.

`SOURCE-PROVENANCE.json` and older `link_gameflow.provenance.json` represent earlier derivative stages. They are retained as historical documents, alongside newer chronological/key/link provenance; they are not asserted to hash today's server/linker. The exact current server/scenario/linker pins live in the selection. A changed source or harness requires a new reviewed selection/freeze.
